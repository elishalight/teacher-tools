# Teacher Tools

A small site of classroom tools. Everything runs in the browser. Nothing is saved on a server.

## Put it on GitHub Pages
1. Create a new GitHub repository (for example `teacher-tools`).
2. Upload everything in this folder to it (drag the files into the GitHub page, then commit).
3. In the repository go to Settings, then Pages. Under "Build and deployment" choose "Deploy from a branch", pick `main` and `/ (root)`, and save.
4. After a minute the site is at `https://YOUR-NAME.github.io/teacher-tools/`.

## Your class data
`seat-planner/` starts with a made-up sample class ("Student 1" and so on), so no real names are on the public site.
Use the Seat Planner's Plans tab: "Backup file" saves your work, "Restore backup" loads it again.
Keep your own backup file private. Do not upload it to the repository.

## Add another tool
1. Make a new folder, for example `timer/`, with an `index.html` inside.
2. Add a card for it in the top-level `index.html`, copying the Seat Planner card.
